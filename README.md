# Ένδεκα Μέτρα ⚽

Παιχνίδι πέναλτι γραμμένο σε καθαρό HTML, CSS και JavaScript. Το γήπεδο ζωγραφίζεται σε Canvas 2D με ψευδο-3D προοπτική, τα animations του UI γίνονται με GSAP και οι ήχοι συντίθενται ζωντανά με Web Audio, χωρίς αρχεία ήχου. Δεν χρειάζεται build step.

## Πώς παίζεται

- Κλικ ή tap πάνω στο τέρμα για να σουτάρεις. Η διακεκομμένη γραμμή δείχνει την τροχιά.
- Τα πλήκτρα `1`–`4` (ή η μπάρα κάτω) αλλάζουν τρόπο εκτέλεσης:
  - **Πλασέ**: ακριβές, πιο αργό.
  - **Κανονιά**: πολύ γρήγορη, αλλά με μεγάλη απόκλιση και τάση να φεύγει ψηλά.
  - **Φάλτσο**: στρίβει στον αέρα και μπερδεύει τον τερματοφύλακα.
  - **Πανένκα**: σουτάκι-τόξο. Αν ο τερματοφύλακας βουτήξει, γκολ με στιλ. Αν μείνει όρθιος, ρεζίλι. Περνάει και πάνω από τον αμυντικό.
- **5 πέναλτι ανά γύρο, 4 γκολ για πρόκριση.** Ο γύρος τελειώνει νωρίτερα μόλις κριθεί.
- **3 δυσκολίες** (Εύκολο, Κανονικό, Δύσκολο). Σε κάθε επίπεδο ο τερματοφύλακας γίνεται πιο γρήγορος και σε "διαβάζει" καλύτερα, αφού θυμάται πού σουτάρεις.
- **Από το επίπεδο 3** μπαίνει ο **Τοίχος**: αμυντικός που περιπολεί μπροστά από το τέρμα και πετάγεται στη γραμμή της μπάλας. Σούταρε μακριά του ή πάνω από αυτόν.

## Δομή

```
index.html   – δομή, HUD, οθόνες
style.css    – όλο το styling του UI
game.js      – σκηνή, χαρακτήρες, φυσική, λογική, ήχος
```

## Ρυθμίσεις

Στην αρχή του `game.js`:

- `ΡΥΘΜΙΣΕΙΣ` – πέναλτι ανά γύρο, γκολ για πρόκριση, επίπεδο εμφάνισης αμυντικού.
- `ΔΥΣΚΟΛΙΕΣ` – αντίδραση, "διάβασμα", ταχύτητα και εμβέλεια τερματοφύλακα, ταχύτητα αμυντικού.
- `ΤΥΠΟΙ_ΣΟΥΤ` – διάρκεια, απόκλιση, τόξο και καμπύλη κάθε εκτέλεσης.
- `ΧΑΡΑΚΤΗΡΕΣ` – χρώματα φανέλας, νούμερα, μαλλιά.

Από την κονσόλα μπορείς να μετρήσεις ποσοστά γκολ:

```js
ΕνδεκαΜετρα.προσομοίωση('κανονικο', 1, 'πλασε', 3000)
```

## Δημοσίευση στο GitHub Pages

1. Ανέβασε τα αρχεία σε ένα νέο repository.
2. **Settings → Pages → Deploy from a branch**, branch `main`, φάκελος `/ (root)`.
3. Σε λίγα λεπτά το παιχνίδι θα είναι διαθέσιμο στο `https://<username>.github.io/<repo>/`.

Για τοπική δοκιμή αρκεί να ανοίξεις το `index.html` στον browser.
